# wptight

Calibrated tight working point of the tree H: SF_rel from a pass/fail fit of the inclusive peak and the yield error balance.

- Source working directory: `charm_work/WPTIGHT_2026-11-19` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/wptight/`](../../docs/results/wptight/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
