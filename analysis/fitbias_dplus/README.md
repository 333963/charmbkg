# fitbias_dplus

Nominal mass-fit model for D+->K-pi+pi+.

- Source working directory: `charm_work/FITBIAS_Dplus_2026-11-20` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/fitbias_dplus/`](../../docs/results/fitbias_dplus/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
