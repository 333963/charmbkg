# catfit

Simultaneous mass fit in score categories instead of the WP70 cut.

- Source working directory: `charm_work/CATFIT_2026-11-20` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/catfit/`](../../docs/results/catfit/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
