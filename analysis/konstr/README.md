# konstr

Background 'by construction' in three weak places of the measurement (K<->pi reflection from data, tagged-fit background, D0 at 2-3 GeV).

- Source working directory: `charm_work/KONSTR_2026-11-20` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/konstr/`](../../docs/results/konstr/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
