# veto_pv

Efficiency of the vertex veto `nPileupVertices == 0` in the inclusive sample and in MC, both runs.

- Source working directory: `charm_work/VETO_pv_2026-11-18` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/veto_pv/`](../../docs/results/veto_pv/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
