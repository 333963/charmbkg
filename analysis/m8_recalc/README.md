Quantities of the methods note recomputed with the new nominal D0 fit model M8.

- Source working directory: `charm_work/M8_przeliczenie_2026-11-20` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/m8_recalc/`](../../docs/results/m8_recalc/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
