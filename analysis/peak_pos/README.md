# peak_pos

Position and width of the D and anti-D mass peaks from data; weak-mode (sagitta) bound.

- Source working directory: `charm_work/PEAK_pos` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/peak_pos/`](../../docs/results/peak_pos/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
