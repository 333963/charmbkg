# lowpt_calib

Feasibility of calibrating eps_S of the tree H by a working-point scan on inclusive D+ (and D0).

- Source working directory: `charm_work/LOWPT_calib_2026-11-18` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/lowpt_calib/`](../../docs/results/lowpt_calib/).
- `out/scan.json` (> 1 MB) is not stored.
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
