# est_spread

Spread of background estimators under the peak as the background-model systematic, D0 and D+.

- Source working directory: `charm_work/EST_spread` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/est_spread/`](../../docs/results/est_spread/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
