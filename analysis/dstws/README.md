# dstws

D* background 'by construction': D0 combined with a track from the Tracks tree (RS / WS / ROT / MIX) as the Delta-m background template.

- Source working directory: `charm_work/DSTWS` (+ `Q_lxplus/dstws`) (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/dstws/`](../../docs/results/dstws/).
- `docs/results/dstws/RAPORT.md` is the full run; `RAPORT_test2.md` and `runs/test/` are test samples and are not to be quoted.
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
