# sd_var

Variation of the diffraction model in Pythia 8 (particle level) for the predicted tagged fraction.

- Source working directory: `charm_work/SD_var_2026-11-19 + Q_lxplus/sd_var` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/sd_var/`](../../docs/results/sd_var/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
