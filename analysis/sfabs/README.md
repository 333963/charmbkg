# sfabs

Absolute scale factor of the tree H at WP70: D+ in three pT bins and D0 at 3-5 GeV.

- Source working directory: `charm_work/SFABS_wynik_2026-11-20` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/sfabs/`](../../docs/results/sfabs/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
