# fmm_data

Fraction of MisMatch* background under the D0 peak from K<->pi twin candidates: MC truth versus data estimators.

- Source working directory: `charm_work/FMM_data` (+ `Q_lxplus/fmm`) (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/fmm_data/`](../../docs/results/fmm_data/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
