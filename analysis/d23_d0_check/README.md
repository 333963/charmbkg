# d23_d0_check

Independent verification of the D0->Kpi peak at pT 2-3 GeV.

- Source working directory: `charm_work/D23_D0_weryfikacja_2026-11-19` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/d23_d0_check/`](../../docs/results/d23_d0_check/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
