# tagxsec

Fiducial cross-section of D0 + proton in AFP and the ratio to the inclusive one.

- Source working directory: `charm_work/TAGXSEC_2026-11-20` (copied as is; comments and reports are in Polish).
- Results, tables and reports: [`docs/results/tagxsec/`](../../docs/results/tagxsec/).
- The scripts keep the paths of the original working area (local `charm_work/...`, EOS / lxplus for the batch parts) and read
  inputs that are not in the repository (npz / h5 / ROOT); they are archived for reference and are not expected to run from here.
